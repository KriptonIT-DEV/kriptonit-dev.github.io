### Endpoint

<Code lang="http" code={`POST ${BASE_API_URL}/api/v1/whatsapp/send-template`} />

### Headers

| Header | Valor |
|--------|-------|
| Content-Type | application/json |
| Authorization | Bearer `{{token}}` |

### Body

| Campo | Tipo | Requerido | Descripción |
|-------|------|-----------|-------------|
| `template_name` | string | Sí | Nombre de la plantilla |
| `to_phone_number` | string | Sí | Número destino |
| `template_body` | array | Sí | Parámetros de la plantilla |
| `tracking_number` | string | No | Número de seguimiento |
| `to_url_tracking` | string | No | URL de seguimiento |

```json
{
  "template_name": "salio_ruta",
  "to_phone_number": "999888000",
  "template_body": [
    {
      "parameters": [
```

### Respuesta Exitosa (200)

```json
{
  "data": {
    "channel": "whatsapp",
    "messages": [
      {
        "id": "wamid.HBgLNTE5MDY1ODk3NjAVAgARGBJFRTBBMTc5N0ExRTIzOTE4NDgA",
        "message_status": "accepted"
      }
    ]
  },
  "errors": {},
  "messages": "OK",
  "status": 200,
  "success": true
}
```

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `data.channel` | string | Canal de envío (`whatsapp`) |
| `data.messages[].id` | string | ID del mensaje enviado |
| `data.messages[].message_status` | string | Estado del envío (`accepted`) |

### Errores

```json
{
  "data": null,
  "errors": {
    "message": "(#132000) Number of parameters does not match...",
    "type": "OAuthException"
  },
  "messages": "Error en parametros de plantilla",
  "status": 400,
  "success": false
}
```

| Código | Mensaje | Posible Causa |
|--------|---------|---------------|
| 400 | Error en parametros de plantilla | Cantidad o tipo de parámetros no coincide con la plantilla |
| 401 | No autorizado | Token expirado o inválido |

:::caution
La cantidad y tipo de parámetros debe coincidir EXACTAMENTE con lo que devuelve `template-params`. Si no coinciden, Meta rechaza el envío.
:::
