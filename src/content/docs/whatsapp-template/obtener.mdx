---
title: Obtener Plantilla por Nombre
description: Consulta los detalles completos de una plantilla específica.
---

import { Tabs, TabItem } from '@astrojs/starlight/components';

### Endpoint 

```
GET /api/v1/whatsapp/template?name={{name}}
```

### Parámetros de Query

| Parámetro | Tipo | Requerido | Descripción | Ejemplo |
|-----------|------|-----------|-------------|---------|
| `name` | string | Sí | Nombre de la plantilla | `salio_ruta` |

### Headers

| Header | Valor |
|--------|-------|
| Authorization | Bearer `{{token}}` |

### Ejemplos

<Tabs>
<TabItem label="cURL">

```bash
curl -X GET "https://kservice.konnect-360.pe/api/v1/whatsapp/template?name=salio_ruta" \
  -H "Authorization: Bearer tu_token_aqui"
```

</TabItem>
<TabItem label="JavaScript">

```javascript
const response = await fetch(
  `https://kservice.konnect-360.pe/api/v1/whatsapp/template?name=${templateName}`,
  { headers: { 'Authorization': `Bearer ${token}` } }
);
const data = await response.json();
```

</TabItem>
</Tabs>

### Estructura de Componentes

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `components[].type` | string | Tipo: `BODY`, `HEADER`, `BUTTONS` |
| `components[].text` | string | Texto con placeholders `{{variable}}` |
| `components[].buttons` | array | Botones asociados |
| `components[].example` | object | Ejemplos de valores para los parámetros |
