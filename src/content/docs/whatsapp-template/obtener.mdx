### Endpoint 

```
GET /api/v1/whatsapp/template?name={{name}}
```

### Parámetros de Query

| Parámetro | Tipo | Requerido | Descripción | Ejemplo |
|-----------|------|-----------|-------------|---------|
| `name` | string | Sí | Nombre de la plantilla | `salio_ruta` |

### Headers

| Header | Valor |
|--------|-------|
| Authorization | Bearer `{{token}}` |

### Estructura de Componentes

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `components[].type` | string | Tipo: `BODY`, `HEADER`, `BUTTONS` |
| `components[].text` | string | Texto con placeholders `{{variable}}` |
| `components[].buttons` | array | Botones asociados |
| `components[].example` | object | Ejemplos de valores para los parámetros |
