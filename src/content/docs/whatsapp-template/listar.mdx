### Endpoint 

```
GET /api/v1/whatsapp/templates
```

### Headers

| Header | Valor |
|--------|-------|
| Authorization | Bearer `{{token}}` |

### Respuesta Exitosa (200)

```json
{
  "data": [
    {
      "category": "UTILITY",
      "id": "438429459276413",
      "language": "es",
      "name": "salio_ruta",
      "status": "APPROVED"
    }
  ],
  "errors": {},
  "messages": "OK",
  "status": 200,
  "success": true
}
```

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `data[].id` | string | ID único de la plantilla en WhatsApp |
| `data[].name` | string | Nombre de la plantilla |
| `data[].category` | string | Categoría: `UTILITY`, `MARKETING`, `AUTHENTICATION` |
| `data[].language` | string | Código de idioma (ej: `es`, `en`) |
| `data[].status` | string | Estado: `APPROVED`, `PENDING`, `REJECTED` |
