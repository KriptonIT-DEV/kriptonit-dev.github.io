## Orden Recomendado

<Steps>

1. `GET /templates` — buscá la plantilla y confirmá que esté `APPROVED`

2. `GET /template-params` — pedí la estructura exacta de parámetros

3. `POST /send-template` — enviá con los valores en el orden que devolvió el paso 2

</Steps>

:::tip
Saltear el paso 2 es lo que produce los errores de cantidad o tipo de parámetro.
:::

## Estructura de una Plantilla

| Componente | Descripción |
|------------|-------------|
| `BODY` | Cuerpo principal del mensaje |
| `HEADER` | Encabezado (texto, imagen, video) |
| `BUTTONS` | Botones interactivos |
| `FOOTER` | Pie de mensaje |

Tipos de botón: `URL` (enlace web), `QUICK_REPLY` (respuesta rápida), `PHONE_NUMBER` (llamada).

Los valores dinámicos van como `{{variable}}`:

```
Hola {{cliente_name}}, tu pedido {{tracking}} está en camino a {{dir_delivery}}.
```

## Estados

| Estado | Descripción |
|--------|-------------|
| `APPROVED` | Aprobada y lista para usar — la única que se puede enviar |
| `PENDING` | En revisión por Meta |
| `REJECTED` | Rechazada, revisá el motivo |

## Tips

- El orden y la cantidad de parámetros deben coincidir exactamente con la plantilla
- Categorías: `UTILITY` para transacciones, `MARKETING` para promociones, `AUTHENTICATION` para verificación
