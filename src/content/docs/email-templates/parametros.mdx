Devuelve las variables `{{variable}}` que la plantilla espera, deduplicadas y en orden de aparición. Es el paso previo a [enviar la plantilla](/email-templates/enviar-plantilla/).

### Endpoint

<Code lang="http" code={`GET ${BASE_API_URL}/api/v1/email/template-params/{id}`} />

### Parámetros de Ruta

| Parámetro | Tipo | Requerido | Descripción | Ejemplo |
|-----------|------|-----------|-------------|---------|
| `id` | int | Sí | `payload_id` de la plantilla | `72` |

### Headers

| Header | Valor |
|--------|-------|
| Authorization | Bearer `{{token}}` |

### Respuesta Exitosa (200)

```json
{
  "success": true,
  "status": 200,
  "code": 0,
  "messages": "",
  "data": {
    "payload_id": 72,
    "canal_id": 1,
    "pyld_nombre": "Bienvenida",
    "pyld_catego": "MARKETING",
    "pyld_estado": 1,
    "pyld_id_wsp": null,
    "pyld_status": "APPROVED",
    "created_at": "2026-01-10T12:00:00.000Z",
    "params": [
      { "name": "name", "type": "text", "value": "" }
    ]
  }
}
```

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `payload_id` | int | ID de la plantilla |
| `pyld_nombre` | string | Nombre de la plantilla |
| `params` | array | Variables detectadas, en orden de aparición y sin repetir |
| `params[].name` | string | Nombre de la variable, sin las llaves |
| `params[].type` | string | Tipo del valor — `text` |
| `params[].value` | string | Siempre vacío: es el hueco que tenés que completar |

La detección admite espacios dentro de las llaves: tanto `{{name}}` como `{{ name }}` se reconocen como la misma variable.

:::note
Esta respuesta **omite a propósito** `template_json`, `template_media`, `template_files_history` y `updated_at`. Si necesitás el cuerpo de la plantilla, usá [Listar Plantillas](/email-templates/listar/).
:::

:::caution
Los parámetros se detectan sobre el campo `html` de la plantilla, mientras que el envío renderiza `html_email`. Si tu plantilla tiene ambos cuerpos distintos, la lista puede no coincidir con las variables que realmente se reemplazan. Verificá el envío antes de mandarlo a producción.
:::

### Errores

**Plantilla no encontrada**

```json
{
  "success": false,
  "status": 400,
  "code": -1,
  "messages": "Detalle del error",
  "data": { "params": [] }
}
```

**ID no numérico**

```json
{
  "success": false,
  "status": 401,
  "messages": "Error de validación",
  "errors": [
    { "path": "id", "msg": "id debe ser un entero" }
  ]
}
```

| Código | Mensaje | Posible Causa |
|--------|---------|---------------|
| 400 | Detalle SQL | La plantilla no existe o no es de canal email |
| 401 | Error de validación | El `id` de la ruta no es un entero |

Los errores de autenticación son comunes a toda la API — ver [Convenciones](/guides/convenciones/).
