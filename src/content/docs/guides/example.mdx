## Widget

:::caution
Tu sitio no debe cargar ***polyfills*** provenientes del framework ***Vue***: entran en conflicto con el widget.
:::

<Steps>

1. Agregá el contenedor en tu `index.html`, o donde arranque tu app:

   ```html
   <div id="your_widget_name"></div>
   ```

2. Importá el script en esa misma página:

   <Code
     lang="html"
     code={`<script type="module">
     import { konnectchat } from "${BASE_API_WIDGET}/widget/konnectchat.es.min.js";

     konnectchat('your_widget_name',
       {
         pagePresentation: {
           title: 'Atencion al cliente', // string - titulo de presentación
           withWhatsAppButton: true, // boolean - ocultar boton de whatsapp
           withHeaderBot: true, // boolean - ver/ocultar header del bot
         },
         // ...
       }
     );
   </script>`}
   />

</Steps>

Las opciones completas de configuración están en [Widget Chat Bot](/guides/widgetbot/).

## APIs y Webhooks

<Steps>

1. Conseguí tus credenciales (`client_id` y `client_secret`) en la sección **CANALES** de tu cuenta Konnect-360.

2. Pedí un token con esas credenciales — ver [Autenticación](/authentication/).

3. Llamá a la API que necesites con el token en el header `Authorization: Bearer`.

4. Si vas a **recibir** eventos en lugar de solo enviarlos, registrá tu URL en [Configuración de Webhooks](/webhooks/configuracion/).

</Steps>
