## Qué vas a encontrar acá

Konnect-360 expone varias APIs REST para integrar mensajería, atención al cliente y flujos con IA
desde tu propio backend o front-end. Todas comparten el mismo esquema de autenticación
(**OAuth 2.0 `client_credentials`**) y devuelven JSON.

Tres URLs base, según qué estés integrando:

| Base | Para qué |
|------|----------|
| <code>{BASE_API_URL}</code> | Autenticación, WhatsApp, canales de chat, webhooks |
| <code>{BASE_API_IAFLOWS}</code> | Flow Chat (flujos conversacionales con IA) |
| <code>{BASE_API_WIDGET}</code> | Widgets embebibles de chat |

## Las APIs

<CardGrid>
    <Card title="Autenticación" icon="approve-check">
        Punto de partida obligatorio. Flujo `client_credentials` con tu `client_id` y
        `client_secret` para obtener el token `Bearer` que va en todas las demás llamadas.

        [Ir a Autenticación →](/authentication/)
    </Card>
    <Card title="Mensajes WhatsApp" icon="comment">
        Envío de mensajes de texto y de texto con multimedia a un número de WhatsApp.

        [Ir a Mensajes WhatsApp →](/whatsapp-messages/)
    </Card>
    <Card title="Plantillas WhatsApp" icon="document">
        Listado de plantillas pre-aprobadas, consulta por nombre, estructura de parámetros y envío
        con valores personalizados.

        [Ir a Plantillas WhatsApp →](/whatsapp-template/)
    </Card>
    <Card title="Canales de Chat" icon="email">
        Consulta de clientes, tickets, historial de mensajes y descarga de archivos multimedia de
        los canales conectados.

        [Ir a Canales de Chat →](/channels-chat/)
    </Card>
    <Card title="Flow Chat" icon="random">
        Chat conversacional contra el grafo completo de un workflow, con estado durable y stream
        SSE del hilo. En fase **experimental**.

        [Ir a Flow Chat →](/flow-chat/)
    </Card>
    <Card title="Webhooks" icon="puzzle">
        Eventos que Konnect-360 envía a tu servidor cuando llega un mensaje por un canal o cuando
        pasa algo en el widget embebido.

        [Ir a Webhooks →](/webhooks/configuracion/)
    </Card>
</CardGrid>

## Widgets

Además de las APIs, hay dos widgets listos para embeber en tu front-end:
el [Widget Chat Bot](/guides/widgetbot/), que atiende con el flujo de IA, y el
[Widget Chat Cliente](/guides/widgetcustomer/), que conecta con un agente humano.

## Por dónde empezar

1. Conseguí tus credenciales en la sección **CANALES** de tu cuenta Konnect-360.
2. Pedí un token en [Autenticación](/authentication/) — todas las demás llamadas lo necesitan.
3. Elegí la API que te toque y seguí su página de **Introducción**: cada una arranca con la URL
   base, los headers y un ejemplo completo.
4. Si vas a recibir eventos, registrá tu URL en [Configuración de Webhooks](/webhooks/configuracion/).
