### Endpoint

<Code lang="http" code={`POST ${BASE_API_IAFLOWS}/api/workflows/:id/flow-chat`} />

Sin body. Crea la conversación y arranca la vuelta 1 para que el flujo **salude** — el saludo no lo manda el cliente, sale del grafo.

### Parámetros de Ruta

| Parámetro | Tipo | Requerido | Descripción | Ejemplo |
|-----------|------|-----------|-------------|---------|
| `:id` | string | Sí | ID del workflow | `00000000-0000-0000-0000-000000000000` |

### Headers

| Header | Valor |
|--------|-------|
| Content-Type | application/json |
| Authorization | Bearer `{{token}}` |

### Respuesta Exitosa (201)

```json
{
  "conversationId": "uuid",
  "executionId": "uuid"
}
```

Guardá el `conversationId`: va en todos los demás endpoints y arma la ruta de los [adjuntos](/flow-chat/adjuntos/). El `executionId` es solo de esta vuelta — cada turno crea uno nuevo.

### Errores

| Código | Cuerpo | Posible Causa |
|--------|--------|---------------|
| 404 | `workflow_not_found` | Workflow inexistente |
| 400 | `published_version_missing` | El flujo no tiene versión publicada |
| 400 | `invalid_snapshot` | Snapshot inválido |
| 403 | `verification_required` / `verification_failed` | Solo con Turnstile configurado |

:::tip
Abrí el [stream](/flow-chat/stream/) apenas recibás el `conversationId`: el saludo ya está corriendo y llega por SSE.
:::
