---
title: Obtener Cliente
description: Consulta la información de un cliente según el canal e identificador.
---

import { Tabs, TabItem } from '@astrojs/starlight/components';

### Endpoint 

```
GET /api/external/customer?channel={{channel}}&identifier={{identifier}}
```

### Parámetros de Query

| Parámetro | Tipo | Requerido | Descripción | Ejemplo |
|-----------|------|-----------|-------------|---------|
| `channel` | string | Sí | Canal de comunicación | `whatsapp` |
| `identifier` | string | Sí | Identificador del cliente | `999888777` |

### Headers

| Header | Valor |
|--------|-------|
| Authorization | Bearer `{{token}}` |

### Ejemplos

<Tabs>
<TabItem label="cURL">

```bash
curl -X GET "https://devkapi.konnect-360.pe/api/external/customer?channel=whatsapp&identifier=999888777" \
  -H "Authorization: Bearer tu_token_aqui"
```

</TabItem>
<TabItem label="JavaScript">

```javascript
const response = await fetch(
  `https://devkapi.konnect-360.pe/api/external/customer?channel=whatsapp&identifier=999888777`,
  { headers: { 'Authorization': `Bearer ${token}` } }
);
const data = await response.json();
```

</TabItem>
</Tabs>

### Respuesta Exitosa (200)

```json
{
  "success": true,
  "data": {
    "cus_id": 1,
    "cus_nombre": "Juan CC",
    "cus_apellido": "",
    "tel_id": 1,
    "mail_id": 0,
    "mail": "",
    "tel_numero": "999888777",
    "rrss_id": "",
    "cia_id": 1,
    "last_ticket_id": null,
    "canal_id": 1
  },
  "code": 0,
  "status": 200,
  "messages": ""
}
```

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `cus_id` | number | ID único del cliente |
| `cus_nombre` | string | Nombre del cliente |
| `cus_apellido` | string | Apellido del cliente |
| `tel_id` | number | ID del teléfono registrado |
| `tel_numero` | string | Número de teléfono |
| `mail` | string | Correo electrónico |
| `cia_id` | number | ID de la empresa |
| `last_ticket_id` | number \| null | ID del último ticket |
| `canal_id` | number | ID del canal |

### Respuesta de Error (400)

```json
{
  "success": false,
  "data": { "canal_id": 1 },
  "code": -1,
  "status": 400,
  "messages": "Error: No hay datos.",
  "errors": { "code": -1, "status": 400 }
}
```

:::tip
Usá el `cus_id` de la respuesta como `customer_id` en el siguiente endpoint para obtener los tickets.
:::
