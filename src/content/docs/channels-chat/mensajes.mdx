---
title: Obtener Mensajes
description: Consulta el historial de mensajes de un ticket específico.
---

import { Tabs, TabItem } from '@astrojs/starlight/components';

### Endpoint 

```
PUT /api/external/ticket/messages
```

### Headers

| Header | Valor |
|--------|-------|
| Content-Type | application/json |
| Authorization | Bearer `{{token}}` |

### Body

| Campo | Tipo | Requerido | Descripción | Ejemplo |
|-------|------|-----------|-------------|---------|
| `ticket_id` | number | Sí | ID del ticket | `169284` |
| `last_msn_id` | number | Sí | Último ID conocido (0 = todos) | `0` |
| `opt` | number | Sí | Opción de consulta | `1` |

### Ejemplos

<Tabs>
<TabItem label="cURL">

```bash
curl -X PUT https://devkapi.konnect-360.pe/api/external/ticket/messages \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tu_token_aqui" \
  -d '{"ticket_id": 169284, "last_msn_id": 0, "opt": 1}'
```

</TabItem>
<TabItem label="JavaScript">

```javascript
const response = await fetch('https://devkapi.konnect-360.pe/api/external/ticket/messages', {
  method: 'PUT',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': `Bearer ${token}`
  },
  body: JSON.stringify({ ticket_id: 169284, last_msn_id: 0, opt: 1 })
});
const data = await response.json();
```

</TabItem>
</Tabs>

### Respuesta Exitosa (200)

```json
[
  {
    "date": "09/04/2025",
    "messages": [
      {
        "hora": "13:07",
        "tipo": 1,
        "fecha": "2025-04-09",
        "agente": "Bot",
        "msn_id": 2306361,
        "mime_id": null,
        "msn_type": 1,
        "msn_texto": "hola",
        "text_fecha": "09/04/2025",
        "customer": true,
        "msn_tipo_str": "text"
      }
    ]
  }
]
```

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `msn_id` | number | ID único del mensaje |
| `msn_texto` | string | Contenido del mensaje |
| `msn_type` | number | Tipo numérico del mensaje |
| `msn_tipo_str` | string | Tipo: `text`, `image`, `video`, `document`, `location` |
| `hora` | string | Hora (HH:MM) |
| `fecha` | string | Fecha (YYYY-MM-DD) |
| `agente` | string | Nombre del agente o bot |
| `customer` | boolean | `true` si es del cliente |
| `mime_id` | string \| null | ID del archivo multimedia |
| `loc_name` | string \| null | Nombre de ubicación |
| `loc_point` | string \| null | Coordenadas de ubicación |

:::tip
Usá `last_msn_id` para paginación incremental. Empezá con `0` para obtener todos y luego pasá el último `msn_id` recibido.
:::
